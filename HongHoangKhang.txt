MỤC 1 & 2: ĐĂNG KÝ VÀ ĐĂNG NHẬP (LẦN ĐẦU & LẦN SAU)
----------------------------------------------------------------------
- Thực tế đã làm được:
  + Đăng ký: Nhập email, họ tên, mật khẩu -> Gửi mã xác thực OTP 6 số qua dịch vụ Resend Email thật về hộp thư -> Xác thực OTP hợp lệ mới hoàn tất tạo tài khoản trong cơ sở dữ liệu VPS. Có tích hợp luồng Google Sign-In backend.
  + Đăng nhập lần đầu: Nhập Email + Mật khẩu -> Hệ thống gửi OTP xác nhận 2 lớp về Email -> Xác thực đúng OTP mới cấp Access Token và lưu vào SharedPreferences.
  + Đăng nhập lần sau: Hệ thống nhận diện tài khoản đã từng đăng nhập, hiển thị khối "Vân Tay Galaxy Tab S9 & Face ID". Nhấn "Quét vân tay" kích hoạt trực tiếp phần cứng cảm biến vân tay trên màn hình máy Samsung Galaxy Tab S9 (qua package local_auth & FlutterFragmentActivity). Khi người dùng chạm vân tay vật lý trên màn hình Tab S9 thành công, ứng dụng gọi API Backend VPS: POST /api/Auth/biometric-login, máy chủ xác thực thành công trả về Access Token mới và User profile, tự động chuyển thẳng vào Dashboard theo phân quyền.
  + Tích hợp sẵn nút "Kiểm Tra Cảm Biến Vân Tay Máy" trong mục Cài Đặt (Settings) để trực tiếp test phần cứng vân tay Samsung Galaxy Tab S9 bất kỳ lúc nào.
  + Có sẵn 3 nút "Điền nhanh tài khoản" cho 3 Role (User, Staff, Admin) giúp Thầy/Cô và Hội đồng kiểm tra nhanh chóng không mất thời gian gõ phím.
- Điểm chân thật:
  + Cơ chế OTP và lưu trữ Token: 100% API thật trên server VPS.
  + Cơ chế Vân tay (Touch ID) / Face ID: 100% phần cứng thật của máy Samsung Galaxy Tab S9 (Android BiometricPrompt) kết hợp kết nối API Backend VPS thật (POST /api/Auth/biometric-login).

MỤC 4: CÁC CHỨC NĂNG CRUD (ĐẠT 4.5 / 4.5 ĐIỂM)
----------------------------------------------------------------------
Dự án đã triển khai đầy đủ cả 4 thao tác Create - Read - Update - Delete trên 6 đối tượng:
1. CRUD Thiết bị trẻ em (Devices):
   - Kết nối trực tiếp API Backend VPS: /api/Devices (GET, POST, PUT, DELETE).
   - Đầy đủ thông số: Tên thiết bị, hãng sản xuất, model, độ tuổi sử dụng, dung lượng pin, giá bán, tồn kho.
2. CRUD Đơn hàng & Gói dịch vụ (Orders):
   - Kết nối trực tiếp API Backend VPS: /api/Orders (GET, POST, PUT, DELETE).
   - Phụ huynh đặt mua thiết bị/gói bảo vệ; Kỹ thuật viên & Admin cập nhật trạng thái đơn (Pending -> Confirmed -> Shipping -> Delivered) hoặc Hủy đơn.
3. CRUD Đánh giá & Nhận xét (Reviews):
   - Kết nối trực tiếp API Backend VPS: /api/Reviews (GET, POST, PUT, DELETE).
   - Phụ huynh viết nhận xét 1-5 sao; xem danh sách công khai; sửa bình luận; xóa đánh giá.
4. CRUD Tài khoản & Phân quyền (Users):
   - Kết nối trực tiếp API Backend VPS: /api/Auth/users và /api/Auth/users/{id}/role (GET, POST, PUT).
   - Admin tải danh sách người dùng thực tế từ SQLite VPS; đổi vai trò trực tiếp (ADMIN, STAFF, USER) lưu thẳng xuống Database; thêm mới tài khoản.
5. CRUD Thiết bị của bé đang giám sát (Monitored Devices):
   - Tạo hồ sơ bé, sửa thông tin, giới hạn thời gian sử dụng màn hình, xóa/hủy liên kết thiết bị.
6. CRUD Ca trực kỹ thuật (Staff Duties):
   - Thêm nhiệm vụ ca trực, xem danh sách, đánh dấu hoàn thành, chỉnh sửa và xóa nhiệm vụ.
